Zestly

Privacy policy

Browser extension by Zane Dev

Last updated: 3 November 2026

Zestly handles only the data needed to recognize and translate text, speech, and pages. It does not collect analytics, sell user data, or use user data for advertising. Zane Dev, the extension author, does not receive the text, images, or audio the extension processes.

Data handled on the device

  • Selected images and screen regions. Images are processed locally by the OCR engine and are not uploaded. Up to eight recent captures may be stored locally for overlays and re-recognition. Captures expire after 30 minutes and are deleted the next time the extension performs its local cleanup. Live translation keeps no captures. It reads each frame in memory and discards it.
  • Microphone and tab audio. When a local speech model is selected, audio is transcribed on the device and is not uploaded. Optional speech models are downloaded from Hugging Face only when the user asks for them.
  • Notebook sessions. Saved transcripts stay in the browser's local extension storage, limited to 40 sessions and 500 lines each, until the user deletes them or uninstalls the extension.
  • Settings and API keys. Preferences and API keys are stored in the browser's local extension storage. An API key is sent only to the endpoint the user configured, and only when that endpoint is used.

Data sent to a service the user selects

  • Recognized or transcribed text. Text is sent to the translation provider the user selected: Google Translate, Microsoft Translator, Yandex Translate, MyMemory, or an OpenAI-compatible endpoint the user configured. During live translation, text from the selected region is sent when it changes, until live translation is stopped. A configured language-model endpoint may also receive the few lines before the current line, as context.
  • Cloud transcription audio. If the user selects a cloud speech model, the audio clip is sent to the transcription endpoint the user configured. It is not sent when a local model is selected.
  • Read-aloud text. Text is sent to Google text-to-speech only when the user requests read-aloud.

Google, Hugging Face, and any user-configured service process data under their own privacy policies.

Retention and deletion

Settings remain on the device until the user changes them, clears the extension's data, or uninstalls the extension. Temporary captures expire after 30 minutes and are also limited to the eight most recent captures. Uninstalling the extension removes its locally stored data.

Limited use

Data handled by the extension is used only to provide OCR, translation, speech, and text-to-speech features. It is not sold, used for advertising, used to determine creditworthiness, or transferred for unrelated purposes.

The use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.
